1. 勉強会後の学習リソース

AWS Black Belt Online Seminar

AWS Black Belt Online Seminar は、AWSの各サービスや設計テーマについて解説している公式セミナー資料です。

PDF資料に合わせてYouTube動画が公開されており、気になるサービスを詳しく知りたいときに使えます。動画は2倍速で見れば30分程度で視聴できるものが多いです。詳細な情報が含まれるため、AWSを0からざっくり学ぶのに適しているかは微妙ですが、詳しく知りたい場合には便利です。

AWS Skill Builder

AWS Skill Builder は、AWS公式のオンライン学習サービスです。

使い方がわかりづらいので、試す際は Qiita記事 を参考にすると分かりやすいです。

動画や読み物形式のコース、学習プラン、試験対策、ラボなどを通してAWSを学べます。 AWSアカウントを作成していなくても、AWS Builder ID を作成すれば利用できます。

ここでいうAWSアカウントは、EC2やS3などのAWSリソースを作るための課金アカウントです。 一方、AWS Builder ID は、Skill Builderなどにサインインするための学習用アカウントのようなものです。

Skill Builderでは、無料で受講できるコースも多くあります。 また、一部には実際のAWS環境を無料で使って操作できるラボもあります(例：第8回で使用したラボ)。ただし、無料でないラボの場合は、有料サブスクリプションが必要になります。

AWSを初めて学ぶ人は、まずSkill Builderで基礎コースを見てから、Black BeltやWorkshopに進むと理解しやすいかもしれないです。

AWS Workshops

AWS Workshops は、手順書に沿って実際にAWSサービスを作りながら学ぶハンズオン教材です。

この勉強会で行ったように、AWSコンソールやAWS CLIを使って、実際にリソースを作成しながら学ぶ形式です。

ただし、Workshopは自分のAWSアカウントで実施することが多く、作成するリソースの種類によっては料金が発生する可能性があります。 実施後は、Cleanup手順に従ってリソースを削除することが大切です。

JP Contents Hub

JP Contents Hub は、日本語のAWSハンズオンやワークショップを探すためのリンク集です。

気になるサービス名で検索し、 AWS Workshopsより多くの日本語のハンズオンを探すことができます。

2. ハンズオン後のリソースが残っていないか確認

不要な課金を避けるため、勉強会で作成したリソースが残っていないか、最後にあらためて確認をお願いします。

請求が発生しているサービスは請求画面やCost Explorerで確認することができます。ただ無料枠が適用されているサービスは表示されず、無料期間が過ぎてからでないと確認できないため、注意が必要です。

3. 無料期間後のAWSアカウントについて

7/15以前に、12か月無料枠でAWSアカウントを作成した方は、無料枠の期間が終了すると、無料枠を超えた利用分が通常の従量課金になります。勉強会で作成したリソースが残っていないか確認をお願いします。

7/15以降に、新しいAWS Free planで作成した方は、Free planの期間が終了すると、Paid planへ変更していなければアカウントが閉じられる扱いになります。そのため、自分でPaid planへ変更していなければ、原則としてそのまま課金が続くわけではありません。

ただし、Paid planへ変更した場合は、クレジットを使い切ったあとの利用分が通常課金になります。学習を続ける場合は、請求画面、無料枠の利用状況、Budgetsなどを確認しながら使うようにしてください。

もうAWSアカウントを使わない場合は、アカウントを閉じることもできます。アカウントを閉じる場合は、rootユーザーでAWSマネジメントコンソールにサインインし、アカウントページから「アカウントを閉鎖」を実行します。

5. 最後に

AWSには多くのサービスがあり、今回の勉強会で扱った内容は、その中の一部です。

それでも、EC2、VPC、RDS、S3、CloudFront、Lambda、SQS、SNSなど、AWSを学ぶうえでよく出てくる基本的なサービスには触れることができたと思います。NAT GatewayとAuroraのハンズオンや、DynamoDBなども扱えればよかったのですが、時間や費用の都合もあり、今回は含めることができませんでした。

AWSはサービス数が多く、難しいと思います。ただ、基本的なサービスを一度触っておくと、別のサービスを学ぶときにも、これはどの部分に関係するサービスなのかを理解しやすくなります。

また、今はAWS公式のBlack Belt、Skill Builder、Workshopのほか、学習記事、動画、AIなど、調べたり学んだりするための手段も以前よりかなり増えています。今回紹介したリンクも、必要になったときに見返すための参考として使っていただければと思います。

この勉強会が、AWSを学ぶきっかけや、今後わからないサービスを調べるときの参考になればと思います。
